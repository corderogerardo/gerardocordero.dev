# Triage Labels

Mapping between the five canonical triage roles and the GitHub label names used in this repo.

| Canonical role | GitHub label |
|----------------|--------------|
| needs-triage   | `needs-triage` |
| needs-info     | `needs-info` |
| ready-for-agent | `ready-for-agent` |
| ready-for-human | `ready-for-human` |
| wontfix        | `wontfix` |

> These are the **exact** label strings the `triage` skill will create and apply. Do not rename them unless you also update this file and re-run the triage setup.
